# HigienizaPro — PWA

Protótipo web instalável com identidade branca e azul, navegação responsiva, scanner de imagem com prévia, registros locais, calculadora matemática de diluição, comparador de fotos e checklist profissional.

## Abrir localmente

Sirva esta pasta com qualquer servidor estático HTTPS (ou localhost). A instalação PWA depende de contexto seguro e suporte do navegador.

## Estado atual — transparência

Este commit é a base visual e funcional inicial. Não inclui ainda autenticação, banco de dados em nuvem, integração real com IA, catálogo de produtos verificados, sincronização entre aparelhos, exportação final de comparativos com logotipo/marca-d'água, nem backend seguro. O catálogo permanece vazio deliberadamente: não inventamos produtos, composição, pH, diluições ou compatibilidades. A calculadora só faz a conta matemática depois que o profissional informa uma proporção confirmada pelo fabricante.
